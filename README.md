## 第 1 週：學習時間紀錄器

在終端機記錄各科的學習分鐘數，查看紀錄並統計學習時間。

### 已完成功能

- 新增科目與學習分鐘數。
- 依新增順序查看所有紀錄。
- 加總相同科目的時間，顯示各科及全部的總分鐘數。
- 去除科目前後空白，拒絕空白科目。
- 拒絕非整數、零與負數分鐘，提示錯誤後仍可繼續操作。
- 處理無效選單選項，並可正常離開程式。

資料目前存於記憶體，結束程式後會清空。本週基本版以新增、查看、統計與輸入檢查為完成範圍。

### 執行方式

已在 Windows、Python 3.14.6 環境驗證，不需安裝第三方套件。

取得儲存庫後，在根目錄執行：

```powershell
python projects/week-01/main.py
```

程式選單：

```text
1. 新增學習紀錄
2. 查看所有紀錄
3. 統計各科時間
0. 離開
```

依序新增「國文 10 分鐘」、「數學 20 分鐘」、「國文 15 分鐘」，選擇統計後得到：

```text
國文:25分鐘
數學:20分鐘
總時間:45分鐘
```

## 學習方向

依實際學習狀況調整進度，難度從簡單逐步提升至中等：

1. **Python 基礎**：變數、條件判斷、迴圈、函式、串列與字典。
2. **實用工具**：文字處理、檔案讀寫、CSV／JSON、輸入檢查與例外處理。
3. **程式組織**：模組拆分、命令列介面、測試與除錯。
4. **資工基礎應用**：資料結構、搜尋與排序、時間複雜度、SQLite 與 API。

初期每個專案預計投入約 2～4 小時。以當週題目的基本要求驗收，延伸功能列為選做。

## 每週實作流程

1. 確認題目、學習目標與基本驗收要求。
2. 先自行實作，遇到問題時透過提示與討論釐清觀念。
3. 測試正常輸入與邊界情況，修正程式。
4. 基本任務驗收通過後，提交並推送至 GitHub。
5. 更新首頁的作品連結、功能與完成狀態。

需要額外說明時，可使用 [專案說明範本](templates/project-readme.md)，記錄執行方式、學習心得與參考來源。
