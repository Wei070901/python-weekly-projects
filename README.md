## 學習方向

依實際學習狀況調整進度，難度從簡單逐步提升至中等：

1. **Python 基礎**：變數、條件判斷、迴圈、函式、串列與字典。
2. **實用工具**：文字處理、檔案讀寫、CSV／JSON、輸入檢查與例外處理。
3. **程式組織**：模組拆分、命令列介面、測試與除錯。
4. **資工基礎應用**：資料結構、搜尋與排序、時間複雜度、SQLite 與 API。

初期每個專案預計投入約 2～4 小時，以完成可使用的基本版為目標，再視情況加入延伸功能。

## 資料夾安排

```text
python-weekly-projects/
├── README.md                    # 作品集首頁與專案目錄
├── .gitignore                   # Python 暫存檔與本機環境的忽略規則
├── projects/
│   └── README.md                # 每週專案的命名與整理方式
└── templates/
    └── project-readme.md        # 每個專案的說明範本
```

每週的程式放在獨立資料夾，例如 `projects/week-01-project-name/`。這只是命名示例，實際專案完成後才建立對應資料夾。

## 每週實作流程

1. 閱讀題目與學習目標，先自行實作基本功能。
2. 執行示範案例，確認正常輸入與邊界情況。
3. 對照參考程式碼，記下差異與修改原因。
4. 使用 [專案說明範本](templates/project-readme.md) 完成 README。
5. 提交程式、必要的範例資料與驗收紀錄。
6. 更新首頁專案目錄，標示實際進度。

專案的說明應區分「自行實作」、「參考解答」及「自行延伸」的內容，讓讀者看見實際學習成果。

## 取得與執行

先安裝 Python 3；每個專案會在自己的 README 標明所需版本與套件。

```powershell
git clone https://github.com/Wei070901/python-weekly-projects.git
cd python-weekly-projects
```

接著進入想執行的專案資料夾，依該專案的 README 操作。各專案獨立執行，不必一次安裝所有專案的套件。

## 每個作品應包含

- 清楚的用途、學習目標與功能說明。
- 可重現的環境設定與執行指令。
- 完整可執行的程式碼。
- 示範輸入、預期輸出與驗收結果。
- 開發心得、遇到的問題與後續改善方向。

公開範例使用虛構資料；密碼、API 金鑰與個人資料不放入儲存庫。
