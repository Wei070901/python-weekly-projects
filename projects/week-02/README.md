# 第 2 週：文字檔關鍵字搜尋器

[返回作品集首頁](../../README.md) · [查看程式碼](main.py) · [查看範例文字檔](notes.txt)

在終端機輸入文字檔路徑和關鍵字，就能從讀書筆記中找出符合的行，並看到它們在原文的位置。

## 已完成功能

- 讀取指定的 UTF-8 文字檔，並保留原檔內容。
- 去除關鍵字前後空白，拒絕空白關鍵字。搜尋會區分大小寫。
- 依原文順序顯示符合的行號與內容。行號從 1 開始，空白行也算一行。
- 統計符合的行數。同一行出現多次關鍵字，仍只計一行。
- 找不到內容、找不到檔案、無法讀取或編碼錯誤時，顯示對應提示。

## 執行方式

使用 Python 3，直接在儲存庫根目錄執行。

```powershell
python projects/week-02/main.py
```

程式詢問檔案路徑時，輸入 `projects/week-02/notes.txt`。接著輸入關鍵字 `Python`，就會看到以下結果。

```text
第1行：今天練習 Python
第3行：Python 可以處理文字檔
共找到2行
```
