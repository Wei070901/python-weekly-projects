# 第 1 週：學習時間紀錄器

[返回作品集首頁](../../README.md) · [查看程式碼](main.py)

在終端機記錄各科的學習分鐘數，查看紀錄並統計學習時間。

## 已完成功能

- 新增科目與學習分鐘數。
- 依新增順序查看所有紀錄。
- 加總相同科目的時間，顯示各科及全部的總分鐘數。
- 去除科目前後空白，拒絕空白科目。
- 拒絕非整數、零與負數分鐘，提示錯誤後仍可繼續操作。
- 處理無效選單選項，並可正常離開程式。

資料目前存於記憶體，結束程式後會清空。本週基本版以新增、查看、統計與輸入檢查為完成範圍。

## 執行方式

使用 Python 3，不需安裝第三方套件。

取得儲存庫後，在根目錄執行：

```powershell
python projects/week-01/main.py
```

程式選單：

```text
1. 新增學習紀錄
2. 查看所有紀錄
3. 統計各科時間
0. 離開
```

依序新增「國文 10 分鐘」、「數學 20 分鐘」、「國文 15 分鐘」，選擇統計後得到：

```text
國文:25分鐘
數學:20分鐘
總時間:45分鐘
```
